# 🎯 Interactive Quiz MCP

An MCP (Model Context Protocol) server that creates interactive multiple-choice quizzes on any topic. It evaluates answers instantly, tracks scores, and provides explanations to improve learning.

## ✨ Features

- Generate quizzes on any topic
- Multiple-choice questions
- Instant answer evaluation
- Score tracking
- Detailed explanations
- Retry incorrect questions
- Interactive learning experience

## 📌 Example Prompts

Quiz me on Full Stack Development.

Generate a DBMS quiz.

Create a Java interview quiz.

Start a Python fundamentals quiz.

## 🚀 How It Works

1. User selects a topic.
2. MCP generates quiz questions.
3. Questions are displayed one at a time.
4. User submits answers.
5. MCP checks the answers instantly.
6. Score and explanations are shown after each question.
